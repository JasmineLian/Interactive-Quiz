# 互動問答測驗

作答者不需要任何帳號，打開網址就能作答。題目、單位與成績都存在 Google 試算表。計分在 Google Apps Script 端進行，正確答案不會傳到作答者的裝置。

| 檔案 | 放哪裡 |
|---|---|
| `index.html` | GitHub repo（用 GitHub Pages 發布） |
| `Code.gs` | Google 試算表的 Apps Script（**不必**放進 GitHub） |

## 一、建立後台（Google 試算表 + Apps Script）

1. 新增一個 Google 試算表，點「擴充功能 → Apps Script」。
2. 刪掉預設內容，貼上 `Code.gs` 的全部內容，然後儲存。
3. 上方函式選單選 `setup`，按「執行」，並依照提示授權。
   執行後試算表會出現五個工作表：「設定」、「題庫」、「作答紀錄」、「逐題明細」、「管理員」，並放入範例題目。
4. 到「管理員」工作表，一人一列填入：

   | 帳號 | 密碼 | 姓名 | 啟用 |
   |---|---|---|---|
   | weishan | 自訂密碼 | 偉珊 | 是 |

   密碼輸入後會自動加密，變成 `sha256$...`。如果沒有自動變，請重新整理試算表，再點選單「問答測驗 → 加密管理員密碼」。
5. 右上「部署 → 新增部署作業」→ 齒輪選「網頁應用程式」：
   - 執行身分：**我**
   - 誰可以存取：**所有人**
6. 按「部署」，複製「網頁應用程式網址」（結尾是 `/exec`）。

## 二、發布前端（GitHub Pages）

1. 打開 `index.html`，找到最上方的這一行：
   ```js
   const API_URL = "https://script.google.com/macros/s/請貼上你的部署ID/exec";
   ```
   換成剛剛複製的網址。
2. 把 `index.html` push 到 repo。
3. 在 repo 的 Settings → Pages → Source 選 `main` 分支 / root，然後儲存。
4. 幾分鐘後，網址 `https://<帳號>.github.io/<repo>/` 就能使用。

## 使用方式

- **作答者**：打開網址 → 填姓名與單位 → 作答 → 交卷。
- **管理員**：點頁面下方「管理員登入」→ 輸入帳號與密碼。登入後可以：
  - 在「作答紀錄」查看所有人的成績、刪除紀錄、匯出 CSV。
  - 在「題庫管理」編輯題目、單位、及格分數、交卷後要顯示的內容。修改後按「儲存題庫」才會生效。
- 也可以直接在 Google 試算表的「題庫」、「設定」工作表修改。修改後作答者重新整理頁面就會套用。

## 注意事項

- 修改 `Code.gs` 後，要到「部署 → 管理部署作業 → ✏ 編輯 → 版本：新版本 → 部署」才會生效。網址不變。
- **管理員帳號**：
  - 新增：在「管理員」工作表加一列。
  - 停用：把「啟用」改成「否」。已登入的人下一次操作就會被登出。
  - 改密碼：在密碼欄直接輸入新密碼，會自動再加密。
- 同一個帳號連續輸錯 5 次密碼，會暫停登入 10 分鐘。
- 管理員登入的有效時間是 6 小時。
- 「設定」工作表的「最後更新」會記錄最後一次儲存題庫的時間和管理員。
- 請勿在作答進行中修改題目的選項順序，否則正在作答的人可能會被以新的答案計分。
