# 互動問答測驗

作答者不需要任何帳號，打開網址就能作答。系統可以同時存放多份測驗，每份測驗有自己的題目與設定。題目、單位、作答紀錄都存在 Google 試算表。計分在 Google Apps Script 端進行，正確答案不會傳到作答者的裝置。

| 檔案 | 放哪裡 |
|---|---|
| `index.html` | GitHub repo（用 GitHub Pages 發布） |
| `Code.gs` | Google 試算表的 Apps Script（**不必**放進 GitHub） |

## 一、建立後台（Google 試算表 + Apps Script）

1. 新增一個 Google 試算表，點「擴充功能 → Apps Script」，貼上 `Code.gs` 的全部內容，然後儲存。
2. 上方函式選單選 `setup` →「執行」，並依照提示授權。完成後會建立這些工作表：

   | 工作表 | 內容 |
   |---|---|
   | 設定 | 共用的單位清單、是否只能從清單選擇 |
   | 測驗 | 每份測驗一列：測驗ID、名稱、開放作答、及格分數、交卷後顯示、最後更新 |
   | 題庫 | 所有測驗的題目，用「測驗ID」區分屬於哪一份 |
   | 作答紀錄 | 每次交卷一列 |
   | 管理員 | 帳號、密碼、姓名、啟用、最後登入 |

   從舊版升級時，原本的題目會自動轉成第一份測驗，作答紀錄會保留。舊的「逐題明細」工作表已經不再使用，可以自行刪除。
3. 到「管理員」工作表，一人一列填入「帳號、密碼、姓名、啟用（是／否）」。「最後登入」會在登入時自動填入。
   密碼以明文存放，**請確保這份試算表只分享給管理員本人**。
4. 右上「部署 → 新增部署作業」→ 類型選「網頁應用程式」：
   - 執行身分：**我**
   - 誰可以存取：**所有人**

   按「部署」後，複製結尾是 `/exec` 的網址。

## 二、發布前端（GitHub Pages）

1. 把 `index.html` 最上方的 `API_URL` 換成剛剛複製的網址。
2. 把 `index.html` 上傳到 repo。
3. 到 repo 的 Settings → Pages，選 `main` 分支、`/ (root)`，然後按 Save。

## 使用方式

- **作答者**：打開網址 → 選擇測驗 → 填姓名、單位 → 作答 → 交卷。
  - 只有一份開放中的測驗時，不會出現選擇欄。
  - 用測驗的專屬連結（`…/?quiz=測驗ID`）打開時，會直接進入那份測驗。
- **管理員**：點頁面下方的「管理員登入」，輸入帳號密碼。
  - **題庫管理 → 測驗清單**：新增、編輯、複製、刪除測驗；切換開放／關閉作答；複製作答專屬連結。
  - **題庫管理 → 單位**：所有測驗共用，修改後按「儲存單位設定」。
  - **編輯測驗**：修改名稱、及格分數、交卷後要顯示的內容，以及題目。完成後按「儲存測驗」。
  - **作答紀錄**：可以依測驗篩選、刪除，或匯出 CSV。

## 注意事項

- 新增的測驗預設為「關閉作答」，題目準備好再開放。
- 刪除測驗時，該測驗的作答紀錄會保留。
- 修改 `Code.gs` 後，要到「部署 → 管理部署作業 → ✏ 編輯 → 版本：新版本 → 部署」才會生效，網址不會變。
- 同一個帳號連續輸錯 5 次密碼，會暫停登入 10 分鐘。管理員登入的有效時間是 6 小時。
- 測驗開放作答期間，請不要修改題目的選項順序，否則正在作答的人可能會被以新的答案計分。
